# Бот-трекер «Срок годности»

Бот помогает следить за сроками хранения продуктов в холодильнике и косметических средств. Пользователь добавляет название и дату истечения срока, а бот присылает уведомление за 2 дня до окончания срока и предлагает рецепты или советы по использованию.

## 1. Назначение

Бот-трекер «Срок годности» помогает пользователям следить за сроками хранения продуктов в холодильнике и косметических средств. Пользователь добавляет название и дату окончания срока годности, а бот своевременно напоминает о приближающемся истечении и предлагает варианты использования: рецепты для продуктов, советы для косметики.

---

## 2. Основные возможности

- Добавление продуктов и косметики с указанием названия и даты истечения срока.
- Просмотр списка всех добавленных позиций с сортировкой по дате.
- Удаление записей.
- Автоматические уведомления за 2 дня до истечения срока (по умолчанию).
- Настройка времени уведомлений и количества дней до напоминания.
- Предложение рецептов на основе продукта, срок которого подходит к концу.
- Для косметики — рекомендации по использованию или совет по утилизации.
- Поддержка категорий: «Продукты» и «Косметика».

---

## 3. Начало работы

1. Запустите бота командой `/start`.
2. Бот поприветствует вас и кратко опишет возможности.
3. Для получения справки используйте `/help`.

---

## 4. Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота, приветствие |
| `/help` | Справка по командам |
| `/add` | Добавить новый продукт или косметику |
| `/list` | Показать все сохранённые позиции |
| `/delete` | Удалить позицию по номеру или названию |
| `/settings` | Настроить уведомления (время, дни до истечения) |

### 4.1. Добавление записи (`/add`)

Бот запросит последовательно:

1. **Название** — например, «Молоко», «Крем для лица».
2. **Дата истечения срока** — в формате `ДД.ММ.ГГГГ` (например, `25.12.2025`).
3. **Категория** — выберите «Продукт» или «Косметика» (кнопками).

После ввода бот сохраняет запись и подтверждает добавление.

**Пример диалога:**

```text
Пользователь: /add
Бот: Введите название:
Пользователь: Молоко
Бот: Введите дату истечения срока (ДД.ММ.ГГГГ):
Пользователь: 30.11.2025
Бот: Выберите категорию:
[Продукт] [Косметика]
Пользователь: Продукт
Бот: ✅ «Молоко» добавлено. Срок до 30.11.2025.
```

### 4.2. Просмотр списка (`/list`)

Бот выводит все записи, отсортированные по дате истечения (сначала ближайшие).

Формат вывода:

```text
1. Молоко — до 30.11.2025 (осталось 5 дней)
2. Крем для лица — до 15.12.2025 (осталось 20 дней)
```

### 4.3. Удаление (`/delete`)

Бот показывает пронумерованный список. Пользователь выбирает номер для удаления.  
Либо можно ввести название точно.

### 4.4. Настройки (`/settings`)

- **Время уведомлений** — по умолчанию 10:00 утра.
- **За сколько дней предупреждать** — по умолчанию 2 дня.
- **Включить/выключить уведомления**.

---

## 5. Уведомления

- Бот проверяет сроки ежедневно в заданное время.
- Если до истечения осталось **2 дня** (или указанное пользователем число), бот отправляет сообщение:

```text
⚠️ Срок годности «Молоко» истекает через 2 дня (30.11.2025).
Хотите приготовить что-нибудь? Вот рецепт:
...
```

- Для косметики:

```text
⚠️ Срок годности «Крем для лица» истекает через 2 дня.
Рекомендуем использовать до конца недели или заменить.
```

---

## 6. Рецепты

- При уведомлении о продукте бот предлагает 1–2 рецепта, где этот продукт является ключевым.
- Рецепты берутся из встроенной базы или внешнего API (например, Spoonacular).
- Пример:

```text
🥞 Рецепт: Блинчики с молоком
Ингредиенты: молоко, мука, яйца, сахар, соль.
Приготовление: смешайте...
```

- Для косметики вместо рецептов бот даёт советы:
  - «Используйте крем для рук, чтобы не выбрасывать».
  - «Проверьте, не изменился ли запах и текстура».

---

## 7. Формат даты

Все даты вводятся в формате `ДД.ММ.ГГГГ`.  
Допускаются также `ДД/ММ/ГГГГ` и `ДД-ММ-ГГГГ`.  
Бот проверяет корректность даты и сообщает об ошибке.

---

## 8. Хранение данных

- Данные пользователей хранятся в базе данных (например, SQLite или PostgreSQL).
- Каждая запись содержит: `user_id`, `название`, `дата_истечения`, `категория`, `дата_добавления`.
- Уведомления реализованы через планировщик задач (cron или встроенный в бота).

---

## 9. Ограничения

- Бот не проверяет реальные условия хранения (температура, влажность).
- Рецепты предлагаются на основе названия продукта; возможны неточности.
- Для косметики бот не оценивает состав и безопасность.
- Максимальное количество записей на пользователя — 100 (может быть изменено).

---

## 10. Техническая реализация (кратко)

- **Язык:** Python (aiogram) или Node.js (Telegraf).
- **База данных:** SQLite для простоты.
- **Планировщик:** APScheduler.
- **Интеграция с API рецептов:** TheMealDB или Spoonacular.
- **Хостинг:** любой VPS или облачный сервис.

---

## 11. Пример использования

1. Пользователь добавляет «Йогурт» до 05.12.2025.
2. 03.12.2025 в 10:00 бот присылает:

   ```text
   ⚠️ Йогурт истекает через 2 дня!
   Попробуйте рецепт: Смузи с йогуртом и бананом.
   ```

3. Пользователь готовит и удаляет запись командой `/delete`.
